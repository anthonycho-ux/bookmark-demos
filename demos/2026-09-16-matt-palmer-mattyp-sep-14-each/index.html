The Daily Demo Machine

Matt Palmer's loop, run as the demo itself: a bot reads x.com/i/bookmarks, picks the most demoable post, an agent builds it, screenshots validate it, Cloudflare previews it, and the link lands each morning. This page replays one cycle, live — you are watching step 4's output.

1 · Pick

Bookmarks → spec
Score each bookmark for demoability. Winner becomes the build spec.

2 · Build

Agent writes the demo
Single self-contained index.html. No CDN, no network calls.

3 · Validate

Screenshot or it didn't happen
Serve locally, render, screenshot, inspect the pixels.

4 · Deploy

Branch → preview URL
Commit, push, Cloudflare Pages builds the preview.

5 · Deliver

Morning link
Bot sends the URL. Coffee, click, done.
